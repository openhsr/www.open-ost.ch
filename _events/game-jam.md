## Was?
Eine Game Jam, bei dem du, alleine oder in einer Gruppe, frei ein Computerspiel (Game) zum Thema "open" entwickelst. Zum Beispiel mit Godot, Unity, ohne UI im Terminal oder sogar ein Game für einen Gameboy Emulator! Wir freuen uns darauf mit euch zu hacken! 

> Wenn Interesse besteht, geben wir eine kurze Einführung in die Open Source Game Engine "Godot".

Am Ende wird euer Game auf itch.io veröffentlicht und ist Open Source.

## Wo?
OST Rapperswil, vor Ort


## Zielgruppe
- alle Interessierten, die gerne ein eigenes Spiel entwickeln möchten
- Zeit am Wochenende 
- ein bisschen Programmiererfahrung wird empfohlen (in einer Gruppe kann eine Person das Programmieren übernehmen)
